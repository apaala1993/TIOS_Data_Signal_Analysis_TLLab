MATLAB-based signal processing and quantitative analysis pipeline for tongue force recordings acquired using a strain gauge transducer during optogenetic tongue stimulation in ALS-SOD1G93A mice. The scripts support preprocessing of raw strain gauge signals, visualization of stimulation-evoked tongue responses, and characterization of tongue force dynamics, including response amplitude, temporal profiles, and stimulation-dependent changes in force generation. This repository provides tools for evaluating optogenetically evoked tongue motor responses and investigating the functional effects of neuromodulation on tongue muscle activity in clinical ALS models.
